Issues and discussions for the writing app, [Nota](https://nota.md/).

How to use this repo:

- Use [Issues](https://github.com/notaapp/talk/issues) to tell about things that don't work.
- Use [Discussions](https://github.com/notaapp/talk/discussions) to request features, ask questions, or just chat about Nota.

Trying Nota Next, the beta of the new native app? Its feedback goes to [notaapp/Nota](https://github.com/notaapp/Nota/issues).
